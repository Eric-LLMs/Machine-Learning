# GBDT-XGBoost-LightGBM

Use XGBoost and LightGBM to predict whether a bicycle has a fault, based on bike-sharing ride data.

**Models:**
- XGBoost (`xgb_model.py`)
- LightGBM (`lightGBM_mode.py`)

**Data:** Bike ride records with features including ride time, distance, cost, lock/unlock status, and service area violations.
