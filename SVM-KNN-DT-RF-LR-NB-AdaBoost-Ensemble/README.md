# SVM-KNN-DT-RF-LR-NB-AdaBoost-Ensemble

Implementations of classical machine learning classifiers with TF-IDF text features, plus an ensemble voting method.

**Classifiers:**
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Decision Tree (DT)
- Random Forest (RF)
- Logistic Regression (LR)
- Naive Bayes (NB)
- Adaptive Boosting (AdaBoost)
- Ensemble (voting)

**Structure:**
- `calssifier/` — individual classifier implementations
- `calssifier/common/` — shared utilities (TF-IDF, preprocessing, evaluation)
- `calssifier/sc_data/` — training/evaluation data and results
