2. **[SVM-KNN-DT-RF-LR-NB-AdaBoost-Ensemble](SVM-KNN-DT-RF-LR-NB-AdaBoost-Ensemble/)**

    This folder contains implementations of several key machine learning algorithms and an ensemble method that combines these models.

	- Support Vector Machine (SVM)
	- K-Nearest Neighbors (KNN)
	- Decision Tree (DT)
	- Random Forest (RF)
	- Logistic Regression (LR)
	- Naive Bayes (NB)
	- Adaptive Boosting (AdaBoost)
	- Ensemble
